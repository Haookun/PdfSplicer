# PdfSplicer

Вы сталкивались с проблемой объединения лицевой и оборотной сторон сканированных документов в один PDF?

PdfSplicer решает эту задачу! Умный инструмент для macOS с современным интерфейсом CustomTkinter и поддержкой перетаскивания файлов, автоматически определяет порядок страниц и объединяет их в единый PDF.

## Особенности
- Современный интерфейс CustomTkinter, лаконичный и элегантный
- Перетаскивание или нажатие для выбора PDF-файлов
- Выбор PDF лицевой и оборотной сторон
- Автоматическое определение и объединение порядка страниц
- Выбор папки для сохранения и быстрый доступ
- Одно нажатие — готовый PDF
- Автоматический пропуск пустых страниц: опция, использует анализ доли белых пикселей для интеллектуального определения и пропуска пустых страниц (включая почти белые страницы сканера) для повышения эффективности.

3. Запустите PdfSplicer, выберите PDF лицевой/оборотной сторон и путь сохранения, нажмите "Начать объединение".

## Упаковка и распространение

### Автоматический скрипт сборки

В проекте есть автоматический скрипт `build_app.sh`, который позволяет одним действием установить зависимости, собрать приложение, создать DMG и проверить запуск.

Использование:
```bash
bash build_app.sh
```
- Скрипт автоматически установит зависимости из requirements.txt и все инструменты сборки.
- Автоматически интегрирует папку bin (pdftoppm и другие инструменты poppler).
- После сборки проверяет запуск приложения и сохраняет лог в dist/app_test.log.
- Артефакты находятся в папке dist/ (App) и в корне проекта (DMG).

Параметры и зависимости можно изменить, отредактировав `build_app.sh`.

## Устранение неполадок

- Если появляется ошибка «pdftoppm не найден» или подобная:
  1. Приложение сначала использует встроенную папку bin (уже интегрировано).
  2. Для ручной установки выполните:
     ```bash
     brew install poppler
     ```
  3. После установки перезапустите приложение.
